# Contributing to ReadMind

Thank you for your interest in contributing to ReadMind! We welcome contributions from everyone.

## Getting Started

1. Fork the repository on GitHub.
2. Clone your fork locally.
3. Create a new branch for your feature or bug fix: `git checkout -b my-new-feature`
4. Make your changes and commit them with descriptive commit messages.

## Development Setup

The project consists of a Node.js backend and a frontend application.

### Backend Setup
1. Navigate to the `backend` directory.
2. Run `npm install` to install dependencies.
3. Start the development server with `npm run dev`.

### Frontend Setup
1. Navigate to the `frontend` directory.
2. Run `npm install` to install dependencies.
3. Start the development server with `npm run dev`.

## Submitting a Pull Request

- Ensure your code follows the existing style conventions.
- Update the documentation if you are changing functionality.
- Push your branch to your fork and submit a pull request against the `main` branch.

We appreciate your help in making ReadMind better!
